# AeroNex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full offline voice-command skeleton: versioned JSON protocol, tested Python Edge server, rule-based EN/TE/HI intent, and a hand-written Flutter app with fakes that runs end-to-end with typed text.

**Architecture:** `protocol/schema.json` is the single contract. `edge/` (FastAPI WebSocket) is the verified reference implementation tested with pytest on this machine. `app/` (Flutter) mirrors the protocol and intent in Dart with fake speech/intent engines; it is code-reviewed here and compiled on a Flutter machine.

**Tech Stack:** Python 3.12, FastAPI 0.137 + Starlette + uvicorn, websockets 15, pytest 8 + pytest-asyncio; Flutter/Dart (hand-written, SDK absent here); JSON Schema (hand-validated, no extra dep).

**Spec:** `docs/superpowers/specs/2026-10-04-aeronex-design.md` (source: `AeroNex_SRS_v1.0.md`)

## Global Constraints

- Normal operation uses no internet, no cloud STT/translation/LLM, no remote API.
- Phone sends structured commands only; never streams raw audio to Edge.
- Every message uses envelope v1: `version`, `message_id` (unique), `type`, `timestamp` (ms epoch), `payload`.
- Edge keys duplicates on `message_id` and returns existing state; never re-executes.
- `ACK` means receipt only (`{"request_id","status":"RECEIVED"}`), never execution.
- `CONNECTED` is shown only with a live heartbeat-confirmed WebSocket session, never on Wi-Fi presence alone.
- Transport, speech, and intent layers stay behind abstract interfaces (`EdgeTransport`, `SpeechEngine`, `IntentEngine`).
- No MAVLink, flight control, autonomy, or vision code in this codebase.
- Python messages serialize in ~0.003 ms; do not add binary framing or native extensions to the relay path.

## Review Focus

- Retry of `cmd-001` after a lost ACK returns the existing command state instead of executing twice — pinned in Task 2 duplicate test.
- `{"version": 2, ...}` is rejected with `ERROR` naming the version mismatch, not silently accepted — pinned in Task 2 validation test.
- 40 rapid reconnects produce one live session and no error-rate retry storm (bounded backoff) — pinned in Task 2 reconnect test.
- "hello drone how are you" yields aparse failure surfaced as `Could not determine the requested command`, never a phantom `MOVE` — pinned in Task 3 negative test.
- `MOVE` with `distance_m: -5` is rejected at parse time with a parameter error, not sent — pinned in Task 3 validation test.
