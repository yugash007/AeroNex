# Architecture v2 — Phases 0, 1a, 1b implementation plan

Spec: [2026-10-11-voice-drone-architecture-v2.md](../specs/2026-10-11-voice-drone-architecture-v2.md). Operator decisions (2026-10-12): build Phases 0 + 1a + 1b now; Tamil/Kannada/Malayalam use sherpa-onnx + IndicConformer CTC now (downloads approved: sherpa-onnx v1.13.8 AAR from GitHub k2-fsa, community IndicConformer int8 exports from Hugging Face, MIT). Version target **0.3.0+12**. Every task is TDD; Flutter/Gradle runs go through the shared lock wrapper; no commits.

## Recorded deviations from the spec (with reasons)

| Spec | This plan | Why |
|---|---|---|
| 4.13 C `c_library_v2` behind a buffer JNI API | **Pure-Kotlin MAVLink 2 codec** (framing, CRC_EXTRA, v2 truncation, signing), verified byte-exact against pymavlink 2.4.50 golden vectors | The spec names a Kotlin codec (mavlink-kotlin) as its sanctioned fallback. With whisper/llama/Cactus removed the app then has **no first-party native code**: armv7 for free, JVM tests on any host (no Linux .so needed on this Windows machine), no JNI hop. |
| 4.3 libfvad VAD | **Kotlin energy VAD** with adaptive noise floor (`audio.EnergyVad`) | Keeps the app free of NDK builds; only used for the PTT tail and spotter gating. libfvad/Silero remain upgrade options behind the same interface. |
| Phase 0 Dart hotfix | Folded into Phase 1a (same round) | The Dart transport is replaced in this round; the hotfix behaviour (STOP/HOLD without confirmation, Cancel = BRAKE, ACK-confirmed modes, always-visible STOP) ships in the 1a service and is proven in SITL. |
| Pigeon | Hand-written typed MethodChannel/EventChannel wrapper | Pigeon is not in the offline pub cache; the wrapper keeps one schema in `session_api.dart` / `SessionChannel.kt`. |
| Gradle modules `:link`, `:safety`, … | Kotlin packages inside `:app` (`link`, `vehicle`, `safety`, `command`, `grammar`, `audio`, `speech`, `session`, `observability`) | Same boundaries, simpler Flutter-hosted build; modules can be split later without code changes. |
| `tools/grammar-gen` JVM tool | Python generator (PyYAML 6.0.2 present) | Build-time only; emits Kotlin tables and assets. |
| Phase 0 reference-phone measurements | Harness built and run on the emulator and host; **real low-end phone numbers remain pending** | No low-end phones are attached. The harness exports JSON the team runs on R0–R5. |
| USB-OTG serial transport | Interface + UDP + TCP now; USB adapter in Phase 2 | Needs real radios and a library download; out of this round. |
| 4.12 STOP payloads pre-encoded at session start | `StopLane` builds the BRAKE/LAND/non-forced DISARM `CommandLong` per STOP; the link encodes each send on its TX thread (fresh sequence, CRC, signature) | Same effect as the spec's 4-step refresh with simpler code. Measured in SITL: STOP → frame queued p50 0.41 ms / p95 0.88 ms; STOP → BRAKE ACK p50 4.9 ms / p95 7.7 ms (loopback, n=10). |
| 4.14/4.15 POSITION_TARGET "only while a move is pending" | The echo stream starts when a live plan containing a move is **shown** (submit) and stays on through the last move; it goes off on invalidate, expiry, STOP, cancel, execution off, link loss and disconnect; dry run never streams | ArduCopter sends the first sample one or two stream intervals after the request, so a stream started with the move frame gave first-move echo 444–472 ms. Measured in SITL: move→echo p50 652 ms before, ≈ 268 ms wall after (n = 20). Telemetry only; on RADIO it adds ≈ 4 Hz × 76 B during the confirmation wait, inside the 4.15 budget. |
| 10.4 M2 in SITL as a raw wall-clock bound | The SITL test asserts M2 at real-time speed (wall × measured simulator speed) **plus** a wall bound of one measured stream period + 60 ms | This host's Gazebo SITL runs at 0.67–0.76× real time, so one 5 Hz stream period is ≈ 300 ms wall; raw wall p95 was 305–311 ms with scaled p95 ≈ 227 ms. The extra wall bound keeps app-side regressions from hiding behind the scaling. |
| 4.12 "re-send until ACK" | Re-send stops when the STOP's ACK arrives, **or** when a heartbeat newer than the STOP decision shows a mode the app did not request (pilot/failsafe took over) → "STOP NOT CONFIRMED … use RC" | A STOP re-send must never override a pilot or autopilot mode change that happened after the press (spec S4 spirit). |

## Waves and tasks

Order: **W1** (T1 ∥ T2 ∥ T3) → **W2** (T4 ∥ T5, then T6) → **W3** (T7, then T8) → **W4** (T9 ∥ T10 ∥ T11, then T12, then T13) → **W5** (T14, T15).
Kotlin root: `app/android/app/src/main/kotlin/com/aeronex/app/`, tests in `app/android/app/src/test/kotlin/com/aeronex/app/`.

### W1 — foundations
- **T1 Golden vectors (Phase 0).** Add a Dart test `app/test/golden/export_golden_test.dart` that runs the current `CommandTranscript.inspect` → `PlanInterpreter` (rules only; AI stubbed to "not recognised") → `FlightPlan.checkVehicle` over every input used in `plan_interpreter_test.dart`, `intent_test.dart`, `flight_plan_test.dart`, `command_transcript_test.dart` (extract inputs; add the spec's two `[unk]` vectors with their *specified* outcomes, flagged `spec_only: true`), and writes `app/test/golden/plan_vectors.json`: `{input, language, vehicle:{landed, altitude}|null, expect:{steps:[{name,arguments,source}]}|{error}}`. Commit the file; the test fails if regenerated output differs.
- **T2 Kotlin MAVLink codec.** Package `link.mavlink`: `MavlinkFrame`, `MavlinkParser` (stream, v1+v2, CRC_EXTRA, signature verify optional), `MavlinkEncoder(sysId=255, compId=190, signing: Signing?)`, `Signing(key32, linkId, timestamps)` with monotonic persisted timestamps; typed messages (HEARTBEAT 0, SYS_STATUS 1, PARAM_REQUEST_READ 20, PARAM_VALUE 22, GLOBAL_POSITION_INT 33, ATTITUDE 30, LOCAL_POSITION_NED 32, COMMAND_LONG 76, COMMAND_ACK 77, SET_POSITION_TARGET_LOCAL_NED 84, POSITION_TARGET_LOCAL_NED 85, RADIO_STATUS 109, TIMESYNC 111, EKF_STATUS_REPORT 193, HOME_POSITION 242, EXTENDED_SYS_STATE 245, STATUSTEXT 253, SETUP_SIGNING 256). `tools/bench/gen_mavlink_vectors.py` (WSL pymavlink) writes `src/test/resources/mavlink_vectors.json` (unsigned + signed + truncated-payload frames); JVM tests: byte-exact encode, decode, bad CRC, bad signature, replayed timestamp rejected.
- **T3 Engine assets + host evaluation (Phase 0).** Download `sherpa-onnx-1.13.8.aar` (GitHub k2-fsa release) and IndicConformer CTC int8 packs for **ta, kn, ml** (and te for comparison) from the Hugging Face exports named in spec 4.6 (prefer a sherpa-onnx-ready export; re-quantize to QUInt8 if the ConvInteger error appears), plus the sherpa KWS zh-en 3M chunk-8 model, into `../tooling/models/sherpa/` with a `manifest.json` (url, bytes, sha256, licence). Evaluate on the host (WSL venv `pip install sherpa-onnx==1.13.8`) with eSpeak NG clips for each language's command phrases: load time, RTF, RSS, transcripts. Write `docs/testing/2026-10-12-phase0-engine-eval.md` + JSON. Commit bench scripts under `tools/bench/` (Vosk load/grammar/filler benches too).

### W2 — Phase 1a core (pure JVM, no Android UI)
- **T4 Link.** Package `link`: `Transport` (UDP, TCP; `kind` incl. `USB_DIRECT_FC`, `USB_RADIO` for policy), `UdpTransport(host, remotePort, localPort, bind: (DatagramSocket)->Unit)`, `TcpTransport`, `LinkSession` (RX thread → `VehicleStateStore`; TX thread with priority queue; 1 Hz GCS heartbeat never throttled; per-transport `TelemetryProfile` requested with SET_MESSAGE_INTERVAL on every (re)connect; POSITION_TARGET at 5/4 Hz only while a move is pending; HOME_POSITION requested on connect; signing optional with UNSIGNED flag; **SETUP_SIGNING refused unless transport is USB_DIRECT_FC**). JVM tests over loopback UDP with a fake vehicle.
- **T5 Vehicle + validator.** Package `vehicle`: immutable `VehicleState` (link age, mode, armed, landed state, mode owner, altitude, NED position/velocity, yaw, battery, health, EKF flags, positionReady, home, last STATUSTEXT, last POSITION_TARGET echo), `ModeOwnership` (APP when the current mode equals the app's last ACCEPTED DO_SET_MODE and no uncommanded change since; else EXTERNAL; failsafe STATUSTEXT ±2 s labels it). Package `command.model`: Kotlin `FlightCommand`/`PlanStep`/`FlightPlan` mirroring Dart rules exactly. Package `safety`: `PlanValidator` (all FlightPlan rules + `checkVehicle` + **home distance ≤ 30 m** with body-frame projection; reject moves while home unknown on the real-hardware profile) gated on T1 validation vectors.
- **T6 Executor + supervisor (+ SITL tests).** Package `safety`/`vehicle`: `ArduPilotExecutor` (takeoff: GUIDED via ACK → ARM → NAV_TAKEOFF → altitude ≥ h−0.4 & IN_AIR; move: SET_POSITION_TARGET_LOCAL_NED frame 9 BODY_OFFSET_NED type_mask 3576 **sent exactly once**, GUIDED only if not already, verified by POSITION_TARGET echo then arrival min(0.5, d/2) & speed < 0.3; land: LAND via ACK → ON_GROUND; COMMAND_LONG re-send with `confirmation`++ per link timeout; REJECTED-after-retry with progress = UNKNOWN), `SafetySupervisor` actor (single thread): `submit(plan, source)` → PendingPlan(token, 15 s, one-use) or immediate execution for STOP/HOLD/status; `confirm(token)`; `cancel()` = STOP while executing; `stop(trigger, heldOneSecond)` per spec 4.12 table (APP airborne → BRAKE, refused → LAND; APP armed on ground → non-forced disarm, refused → BRAKE + alarm; EXTERNAL → nothing unless held 1 s; pre-encoded payloads; re-send ≤ 3 s then "STOP NOT CONFIRMED"); plan aborts on external mode change, stale link, fence/failsafe STATUSTEXT; outcomes COMPLETED/NOT SENT/REJECTED/UNKNOWN/SKIPPED; dry-run mode returns NOT SENT without a link; trace events. JVM tests with a scripted fake ArduCopter; **SITL integration tests** (`-Psitl`, UDP 127.0.0.1:14550 against the WSL simulator): takeoff→move→land, STOP mid-move → BRAKE ACK and stop, Cancel = STOP, external mode change → EXTERNAL abort, GPS-denied BRAKE refusal → LAND fallback (SIM param), home-distance rejection.

### W3 — service and thin client (Phase 1a)
- **T7 FlightSessionService + channel.** Package `session`: foreground service (`connectedDevice` now; `microphone` added in T12) with notification + STOP action (POST_NOTIFICATIONS flow), owns LinkSession/Supervisor; `SessionChannel` MethodChannel `aeronex/session` (`connect(cfg)`, `disconnect`, `setExecution(bool)`, `submitPlan(json)`, `submitText(text, lang)` (T10 later), `confirm(token)`, `cancel`, `stop(hold1s)`, `pttDown/pttUp` (T12)) and EventChannel `aeronex/session/state` snapshots at 5 Hz (Tier L) / 10 Hz. `MainActivity.dispatchKeyEvent`: Volume-Down → STOP (any press), Volume-Up → PTT hold (when a session is active and the flight screen is foreground). Manifest permissions/service. Remove `NativeMavlink.kt` usage.
- **T8 Flutter thin client.** `lib/features/session/session_api.dart` (typed wrapper + `SessionSnapshot`), screens: **Flight** (giant STOP at top, hold 1 s for EXTERNAL override; PTT bar placeholder until T12; plan card with countdown + source chip; large CONFIRM; status line with mode owner; degradation chip; **tap command pad**; typed input), **Link setup** (saved settings, transport, execution switch), **Models**, **Diagnostics** (p50/p95 per stage, raw telemetry). Dart keeps parsing typed/spoken text in 1a and calls `submitPlan`; delete `mavlink_transport.dart` and the Dart executor path. Tests rewritten against a fake session channel; all safety behaviours from 0.2.0 tests preserved at the new boundary.

### W4 — speech in the service (Phase 1b)
- **T9 Canonical grammar + generator.** `grammar/intents.v1.yaml`, `grammar/lexicon/{en,hi,te,ta,kn,ml}.yaml` extracted from the Dart tables (provisional entries marked), numbers 0–100 + halves, negation, stop words, connectives, loanwords in script, fillers. `tools/grammar-gen/gen.py` emits `…/grammar/GrammarTables.kt`, `app/android/app/src/main/assets/grammar/vosk_{lang}.json` (phrase list: every adjacent word pair of every template + fillers + `[unk]`), `stop_{lang}.json`, `ctc_lexicon_{lang}.json`, fixtures; fails if a command word is missing from a Vosk model's words list.
- **T10 Kotlin parser port.** Package `command`: `Normalizer` (NFC, ZWJ/ZWNJ, nukta, loanword map, number tables), `CommandSplitter`, `StepParser`, `PlanParser`, `TranscriptInspector` (port of `CommandTranscript.inspect`), `[unk]` policy, Vosk n-best margin (Δ=0.1), CTC template matching (slots exact; fixed-word edit distance d1 ≤ 1, d2 − d1 ≥ 2). **Gate: 100% of T1 golden vectors** (spec_only vectors per spec). `submitText` in the service uses it.
- **T11 Audio + engines.** Package `audio`: `AudioCapture` (VOICE_RECOGNITION 16 kHz mono, blocking 20 ms reads, preallocated ring ≥ 1 s, 500 ms pre-roll, silenced-capture detectors), `EnergyVad`, adaptive tail (60 ms non-speech, max 250 ms). Package `speech`: `SpeechEngine` interface; `VoskGrammarEngine` (resident model; command + stop grammar recognizers; partial words; `setMaxAlternatives(3)`; stop token in partials on 2 consecutive 100 ms steps); `SherpaCtcEngine` (IndicConformer NeMo CTC via the AAR's Kotlin API, decode after tail); `SherpaKwsSpotter` (zh-en chunk-8, "stop"/"hold"); `EnginePolicy` (tier by 64-bit ABI + totalMem 3.3/5.5 GiB; Go flag → strict profile; Tier L: exactly one runtime; CTC on Tier L only if the first-session benchmark passes RTF ≤ 0.15); model profiles + manifests in `VerifiedModelStore`/`LocalModelInventory` for the new packs.
- **T12 Wire speech into the service + PTT.** FGS type `microphone|connectedDevice`; PTT intents from the bar and Volume-Up; STOP keys end PTT; recognizer → parser → supervisor; spotter → `stop()`; traces for every span in spec 5. Flutter PTT bar and language picker; Dart parser and `LocalInference.interpret` path removed.
- **T13 Removal + multi-ABI.** Delete whisper.cpp, llama.cpp, Cactus, `inference.cpp`, `cactus_jni.cpp`, `NativeMavlink.kt`, the CMake build, LFM/Whisper/Whistle/Needle model profiles and UI; `abiFilters` armeabi-v7a + arm64-v8a (x86_64 in debug only); update `tools/check_android_package.py` (both ABIs, 16 KB alignment for 64-bit, Vosk/JNA contract, sherpa libs present, no removed libs); update/remove obsolete Kotlin host tests; version 0.3.0+12.

### W5 — verification and Phase 0 harness

Run on the emulator; document as non-representative.
- **T15 Full verification.** All Flutter + JVM + Python suites; SITL tests; release APK checks for both ABIs; emulator end-to-end against Gazebo (typed plan, tap pad, STOP button mid-move → BRAKE, Volume-Down STOP); docs (README, RUN_SIMULATION, test report `docs/testing/2026-10-12-v0.3.0.md`).
